
##  ShopZone - AI Prompts

This file contains the prompts used during the development of the ShopZone e-commerce project.

The prompts were used for learning, planning, debugging, improving UI, and understanding React concepts.

---

## 1. Project Planning

### Prompt

> I want to build a simple e-commerce website using React.js. The project should have Home, Shop, Product Details, Cart, Checkout and Contact pages. Guide me step by step and explain each concept while building it.

### Purpose

Used to plan the overall structure and features of the ShopZone project.

---
